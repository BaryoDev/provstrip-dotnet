# Contributing

Contributions are welcome, including small ones. This adds to the
[BaryoDev-wide guide](https://github.com/BaryoDev/.github/blob/main/CONTRIBUTING.md); where the two
disagree, this file wins.

If you want to take something, comment on its issue first so we do not both write it.

## Getting it running

```sh
git clone https://github.com/BaryoDev/provstrip-dotnet.git
cd provstrip-dotnet
dotnet test provstrip-dotnet.slnx
```

The pack step tests run real `dotnet pack` processes, so that project takes a minute.

## Four constraints that decide most design questions

**Splice, never re-encode.** Kept bytes are copied, dropped bytes are skipped, and pixel data is never
decoded. The only rewrite is the EXIF block reduced to its orientation tag, plus header fields that must
follow a removal (the WebP `VP8X` flags and RIFF size). A change that decodes an image is the wrong change.

**Fail closed.** Every segment is a rule match, on the format's safe list, or unknown, and unknown stops the
operation. When a parser meets something it does not understand, it refuses the file or reports the segment.
It never guesses.

**Rules are data.** A new marker inside a format already parsed is an edit to `Rules/rules.json`, not code. A
new format is a new `IContainer`, registered in `ProvStripEngine`.

**Verify after strip.** The output is parsed again, and its findings must equal the input's minus the ones
removed. Nothing is written before that check passes.

## Tests

**Every change needs a test that fails without it.** If you cannot write one, say so in the description and
explain why.

Fixtures are generated by `tests/fixtures/make-fixtures.sh`, which needs `c2patool`, `cjpeg`, `cwebp`,
`openssl` and `python3`. The C2PA manifests are real, signed with a throwaway certificate made at fixture
time, and name no real tool. Never commit a file that carries a real tool's attribution or a private key.
